# Module terminal-sdk

Run gift card operations in Facilipay from your own Android app on a Facilipay terminal. Start with
[FacilipayGift.Contract][io.facilipay.terminal.FacilipayGift.Contract] and
[GiftRequest][io.facilipay.terminal.GiftRequest]; every request ends with a
[GiftResult][io.facilipay.terminal.GiftResult]. The guide is at
https://developers.facilipay.io/terminal/.

# Package io.facilipay.terminal
